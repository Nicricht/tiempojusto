# TiempoJusto

Repositorio técnico del proyecto **TiempoJusto**.

## Estado actual

El proyecto se encuentra en la fase de traducción de la especificación funcional a ingeniería ejecutable.

### Artefactos principales

- `docs/database/TiempoJusto_Modelo_ER_Fisico_V1_0.docx`: modelo ER físico inicial.
- `database/schema/TiempoJusto_PostgreSQL_Schema_V1_0.sql`: schema PostgreSQL/PostGIS inicial.
- `docs/state-machines/TiempoJusto_State_Machines_Ejecutables_V1_0.docx`: especificación de máquinas de estado.
- `backend/state-machines/TiempoJusto_State_Machines_Java21_V1_0.zip`: implementación Java 21 y pruebas.
